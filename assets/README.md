# Brand assets (`assets/`)

Static artwork served by the web UI. Replace files here without changing import paths in code.

| Path | README |
|------|--------|
| [`logo/`](logo/README.md) | Wordmark and favicon SVGs |

Vite alias: `@assets` → repo `assets/` (see `apps/web/vite.config.ts`).

After replacing images, restart `make dev-web` or rebuild the web container.
